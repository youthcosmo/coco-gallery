# COCO Gallery

A minimal, aesthetic photo gallery web application built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**.

## Features

- **App Router & Turbopack**: Fast modern Next.js setup
- **Tailwind CSS v4**: Beautiful custom palette (`#E5C3D1` background, `#613F75` accent)
- **Interactive Gallery**: Filter by category, real-time search, like counters, and full-screen modal preview
- **Photo Registration**: Add custom photos dynamically

## Getting Started

Run the development server in PowerShell:

```powershell
npm.cmd run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the gallery.
